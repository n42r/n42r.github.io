Each post in the series sets, in front matter: series: (grouping key) series_num: (order within the series) series_title: (optional; falls back to the series slug) We compare series_num values directly (no array-index math), so ordering works regardless of post date. Renders nothing when no `series` or only a single part. {% endcomment %} {%- if page.series and page.series_num -%} {%- assign this_num = page.series_num -%} {%- assign same = site.posts | where: "series", page.series -%} {%- assign total = same.size -%} {%- assign current = 1 -%} {%- assign prev_post = nil -%} {%- assign next_post = nil -%} {%- assign seen_next = false -%} {%- for post in same -%} {%- assign n = post.series_num -%} {%- if n < this_num -%} {%- assign prev_post = post -%} {%- assign current = current | plus: 1 -%} {%- elsif n > this_num and seen_next == false -%} {%- assign next_post = post -%} {%- assign seen_next = true -%} {%- endif -%} {%- endfor -%} {%- if total > 1 -%}
